数字卦 · 三组数字起卦（v10）
==============================

【怎么打开】
电脑：用浏览器（Chrome / Edge / 360 / QQ浏览器等）打开「shuzigua.html」即可，双击或拖入浏览器都行。
    也支持作为本地离线工具使用，无需安装、无需联网。
手机：把整个压缩包传到手机，解压后用手机浏览器打开「shuzigua.html」即可。

【三种取数法】
1. 万年历自动换算（最推荐）：选新历月、日、时辰 → 自动得农历月/日/时辰 + 三组数字
2. 时间起卦法（梅花易数专用）：换算区内置年支+月+日+时支的起卦公式（上卦/下卦/动爻）
3. 心里报三个数：随机三组，一键起卦

【两种算法】
1. 梅花易数：传统三组数字起卦，依《易经》九级断语终判，附体用生克（五行对比）与风水趋吉建议
2. 小六壬（诸葛马前课）：三数定六神（大安/留连/速喜/赤口/小吉/空亡），初→中→末三传，末传为主断

【九级断语】
元吉 · 大吉 · 吉 · 无咎（金黄）
悔 · 吝 · 厉 · 咎 · 凶（朱红）
平（吉凶未显，依卦象义理而断）

【怎么看结果】
- 顶部大字金黄=吉利，朱红=不吉
- 下方面板：1)第一组下卦 2)第二组本卦 3)第三组动爻+体用生克+风水方位
