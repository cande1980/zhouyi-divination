# 东方秘境 · 命理排盘

> 一款单文件网页应用，集 **八字（子平）· 易经问卦 · 奇门遁甲 · 紫微飞星 · 老黄历** 于一体。
> 打开即用，无需安装；**所有推算均在本机浏览器内完成，不上传任何数据**。

**出品**：江门市东州设计工程有限公司　|　**作者**：东洲星语　|　版本 V0.28.9

本地使用：下载本仓库，直接双击 `index.html` 即可（无需服务器）。

## 功能一览

| 模块 | 说明 |
|---|---|
| **八字排盘** | 子平法，四柱干支、十神、五行、大运流年 |
| **易经问卦** | 六十四卦，卦辞爻辞 + 白话直断，含变卦复盘 |
| **奇门遁甲** | 阳盘拆补法，九宫布星门神仪，金框标用神宫，角标门迫/击刑/旬空，附白话注解 |
| **紫微斗数** | 飞星派（梁若瑜），十四主星、生年四化、宫干飞化连线、大限顺逆 |
| **老黄历** | 宜忌、冲煞、彭祖百忌，支持任意日期查询 |
| **小六壬 / 梅花易数** | 三数起卦，快速断吉凶 |
| **书阁** | 经阁（图鉴）· 习堂（练习）· 录（卦事记录） |
| **命理书阁** | 六门书封入口：前世卷、未来卷、紫微、黄历等 |
| **简繁切换** | 全站简体 / 繁体一键切换 |
