九级断语 · 吉凶量表
判法：扫描卦辞 / 爻辞中的断语字，取其主断。否定式（无咎 · 无大咎 · 何咎 · 悔亡 · 无悔）一律归入「无咎」级； 同一句读内「凶类＋吉类」连用者（如「厉无咎」「厉终吉」）属转危为安句式，以吉类为主断、凶类降为前置警示； 若句读已断（如「征凶。居贞吉。」）则凶断不可翻。辞中未著断语字者列为「平」，须依卦象义理而断。
占卜攻略 · 怎么取数字（一看就懂，含全部取数法详解）
占卜只做一件事：把你要问的事，变成 3 个数字填进下面三格，程序自动起卦断吉凶。
数字最好"从事情本身来"——事情定在哪天、几点，就用那天的农历月、农历日、时辰；事情还没定时间，就心里随手想三个数。一事一卦，问题越具体越准。

最推荐方法一：按事情发生的那天那个点取数（用上面的万年历换算器）

凡是有"具体日子"的事——谈项目、相亲、面试、考试、结婚、开业、搬家、出行——就用事情发生那天的农历月、农历日、时辰来测。打开上方「万年历自动换算」，选好新历几月、几号、几点，三格数字自动填好。

例1阿强约了客户，下个月 9月20日 下午3点 面谈项目合作意向。换算器选"9月、20日、15时"→ 自动得 农历八月初十 · 申时 → 第①格=8（农历月） 第②格=10（农历日） 第③格=9（申时），即以此断这次会谈的成败吉凶。
例2小美与小明定于 10月1日 上午10点 举办婚礼。换算器选"10月、1日、10时"→ 自动得 农历八月廿一 · 巳时 → 第①格=8 第②格=21 第③格=6（巳时），即以此断这桩婚事是否和美。新人算日子结婚、订婚、领证同理。

小提示：事情还没定时间，就用你问卦的当下日期时辰来算，或改用方法二。

最快方法二：心里报三个数

心里默念问题，随口报三个数（或看手表秒数、车牌尾号、小票尾数），直接填进三格。念起即取，不要犹豫、不要改来改去。

例你想问"这个月能不能签下合同"，心里冒出 3、7、12 → 第①格=3 第②格=7 第③格=12（12÷6 余0 → 第6爻动）。

算法梅花易数 · 三组数字怎么定卦

第①格=下卦（内），第②格=上卦（外），第③格÷6 定动爻（第1–6爻）。三格齐备即起出本卦，动爻阴阳互换得变卦；吉凶以终判（动爻爻辞）为主。

例 735 / 993 / 455 → 下艮(7) 上乾(1) 动 455÷6→5 → 天山遁 · 五爻 · 火山旅，终判吉。
其它取数法详解（进阶 · 同样把结果填进三格即可）

① 时间起卦法（不用换算器、手工算）

记四样数：年地支（子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12）、农历月、农历日、时辰（子1…亥12）。
上卦数=(年支+月+日)÷8 余数（余0记8）；下卦数=(年支+月+日+时)÷8 余数；动爻数=(四项和)÷6 余数（余0记6）。
填：第①格=下卦数　第②格=上卦数　第③格=动爻数

例2026丙午年（午=7）农历八月廿五 午时（7）：上=(7+8+25)=40÷8 余0→8；下=(7+8+25+7)=47÷8 余7；动=47÷6 余5 → 填 7、8、5，得 地山谦 · 五爻动。

② 字数法（用你问的话）

把想问的话写下来。第①格 = 后半句字数÷8 余数；第②格 = 前半句字数÷8 余数；第③格 = 总字数÷6 余数。

例问"我何时脱单"（5字）→ 前2字"我何"、后3字"时脱单" → 填 3、2、5。

③ 姓名法（问两人缘分 / 合作）

第①格 = 你的姓名总笔画÷8 余数；第②格 = 对方姓名总笔画÷8 余数；第③格 = 两人笔画和÷6 余数。

例张三（10画）测与李四（12画）：①=10÷8 余2　②=12÷8 余4　③=22÷6 余4 → 填 2、4、4。

④ 物数法（看到什么数什么）

第①格 = 所见东西个数÷8 余数；第②格 = 当下时辰数÷8 余数；第③格 = 两者和÷6 余数。

例见 3 只鸟飞过，此时午时（7）：①=3　②=7　③=(3+7)÷6 余4 → 填 3、7、4。

⑤ 声音法（听几声）

第①格 = 第一段声音次数÷8 余数；第②格 = 第二段次数÷8 余数；第③格 = 总数÷6 余数。

例敲门先响 2 下、停顿、再响 5 下：①=2　②=5　③=7÷6 余1 → 填 2、5、1。

⑥ 方位 / 颜色法

方位后天数：北1 西南2 东4 东南5 中5 西北6 西7 东北8 南9。颜色五行数：金(白银)=1/2 木(青绿)=4/5 水(黑蓝)=6 火(红紫)=3 土(黄棕)=7/8。
第①格=方位数÷8 余数；第②格=颜色数÷8 余数；第③格=两者和÷6 余数。

例欲测向东北方发展、当日着红衣：①=8　②=火=3　③=11÷6 余5 → 填 8、3、5。

⑦ 诚心随机法（心乱没着落时）

闭眼随手敲三下、看手表秒数、记公交班次、小票尾数——直接填三格。数贵在"诚"与"感"，起念即取，想得越久反而越不准。

模式小六壬六神速查（切到"小六壬"模式用）

六神顺序：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡（1–6 循环）。取三数：①自大安数第①数得初传；②自初传续数第②数得中传；③自中传续数第③数得末传（主断）。适用：临时起意、一事速断——出行、见人、小事成败、随手问吉凶。

大安=吉·木 ｜ 留连=凶·水 ｜ 速喜=吉·火 ｜ 赤口=凶·金 ｜ 小吉=吉·木 ｜ 空亡=凶·土。
例：报 7、13、8（=丙午年七月十三未时）→ 初传大安 → 中传大安 → 末传留连。
记住：三格数字中 第③格最要紧——它决定"动爻"，是断吉凶的关键。填完自动出卦，重点看最上方大字的终判与变卦（见"九级断语 · 吉凶量表"）。
